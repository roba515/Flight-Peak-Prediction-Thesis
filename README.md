# Flight Peak Level Prediction Using Machine Learning & Deep Learning

## 📋 Project Overview
This project predicts flight demand and peak travel periods using historical U.S. Bureau of Transportation Statistics (BTS) data. It compares **XGBoost** and **Artificial Neural Networks (ANN)** models and includes a complete interactive workflow and web interface.

## 📊 Dataset Source
* **Source:** U.S. Bureau of Transportation Statistics (BTS) / Kaggle
* **Dataset Link:** [Kaggle Flight Delay and Cancellation Dataset (2019-2023)](https://www.kaggle.com/datasets/robikscube/flight-delay-and-cancellation-dataset-2019-2023)

## 🛠️ Project Contents
* **Notebook File:** Contains data preprocessing, feature engineering, model training, evaluations, visualizations, and the Streamlit interface code.
